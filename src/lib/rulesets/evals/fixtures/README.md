# Rule extraction fixtures

The three HTML files are original synthetic test documents authored for Just Cards,
covered by the repository's MIT license. They describe test variants in our own
words. They are not downloads, verbatim excerpts, authoritative rule references,
or representations of any publisher's current wording.

The golden tests retain Bicycle/Pagat URLs as source-URL detection inputs and
historical provenance for the test scenarios. Network fetching is not performed by
these fixtures. Fixture filenames and the HTML `data-fixture="synthetic"` attribute
identify the replacement input explicitly.

These replace complete saved publisher pages previously committed in this directory.
Those earlier versions remain in Git history. Removing current files does not remove
historical copies; that requires a separately agreed history rewrite or publishing
from a fresh reviewed history.
